# 🎬 Movie Website

A modern, responsive movie website showcasing currently playing films, upcoming releases, Azerbaijani cinema history, and latest cinema news — inspired by the Nizami Cinema Center.

## 📸 Features

- 🎥 **Movie Gallery** – Displays featured movies with booking option
- 🕒 **Currently Playing & Coming Soon** sections
- 📽️ **Pearls of Azerbaijani Cinema** – Historical timeline of films
- 📰 **Latest News** – Cinema updates and cultural events
- 🧾 **About Us** – Info on Nizami Cinema Center and its evolution
- 📄 **Order Form** – (In development) for movie ticket or merchandise requests
- 🎨 Responsive UI using custom CSS and Font Awesome
